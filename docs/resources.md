# People & sources I learn from

Nothing on this site was invented in a vacuum. The endpoint-management community has been sharing hard-won lessons in the open for years, and most of what I know traces back to the people and docs below. If something here helped you, theirs will too.

## Community

- **[MSEndpointMgr](https://msendpointmgr.com/)** — the community hub for Intune, ConfigMgr and modern management; deep, practical, multi-author.
- **[Anoop C Nair — HTMD Community](https://www.anoopcnair.com/)** — one of the largest SCCM/Intune knowledge bases, and an active community.
- **[Rudy Ooms — Call4Cloud](https://call4cloud.nl/)** — deep dives into Intune internals and the awkward edge cases nobody else documents.
- **[Andrew Taylor](https://andrewstaylor.com/)** — a reference point for PowerShell + Graph automation of Intune, and a near-weekly newsletter.
- **[Jannik Reinhard](https://jannikreinhard.com/)** — Intune and AI/Foundry, including agent patterns over endpoint data.
- **[Ugur Koc](https://ugurkoc.de/)** — Intune and Security Copilot, and genuinely useful free open-source tools.
- **[Peter van der Woude](https://www.petervanderwoude.nl/)** — long-running, precise Intune configuration write-ups.

## Microsoft's own docs

- **[Microsoft Learn — Intune](https://learn.microsoft.com/en-us/intune/)** — the source of truth; every claim here should trace back to it.
- **[Microsoft Graph docs](https://learn.microsoft.com/en-us/graph/)** and **[Graph Explorer](https://developer.microsoft.com/en-us/graph/graph-explorer)** — for seeing exactly what the portal calls underneath.

## Prior art this project builds on

- **[M365Documentation](https://github.com/ThomasKur/M365Documentation)** by Thomas Kurth (GPL-3.0) — the Intune documentation collector uses it (installed separately, not vendored).
- **[SMSAgent / Trevor Jones](https://smsagent.blog/)** — the Automation → Blob → CSV → Power BI reporting approach follows well-established community prior art.
